# 文献浏览总结器

一个功能完善的学术文献浏览总结器应用程序，用于自动分析和总结PDF格式的学术文献。

## 功能特性

- **PDF文献扫描**：自动扫描指定文件夹中的所有PDF文件
- **智能信息提取**：从PDF文献中提取结构化信息
  - 题目
  - 作者
  - 摘要
  - 研究问题
  - 使用理论
  - 研究方法
  - 研究步骤
  - 研究结果
  - 贡献
  - 关键词
  - 发表期刊/会议
  - 发表年份
  - 研究局限性
- **Excel导出**：将分析结果导出为格式化的Excel表格
- **用户友好界面**：简洁直观的图形界面

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行程序

```bash
python main.py
```

## 使用方法

1. 点击"浏览"按钮选择包含PDF文献的文件夹
2. 系统会自动扫描并显示找到的PDF文件
3. 点击"开始分析"按钮开始分析文献
4. 分析完成后，点击"导出Excel"按钮保存结果

## 系统要求

- Python 3.8+
- Windows/Linux/macOS
